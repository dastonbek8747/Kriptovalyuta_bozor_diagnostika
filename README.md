# 📈 Kriptovalyuta Bozor Diagnostikasi

Turli kripto birjalaridan real vaqt ma'lumotlarini olib, narx va bozor holatini tahlil qiluvchi Streamlit paneli.

---

## ✨ Imkoniyatlar

- 🔀 **Ko'p birja:** Binance, Bybit, OKX, Kraken, Coinbase, KuCoin (ccxt orqali)
- 📊 **Interaktiv grafiklar:** Plotly bilan narx dinamikasi
- 🕐 **Turli vaqt oraliqlari** (timeframe)
- 📉 **Bozor ko'rsatkichlari:** narx, hajm, o'zgarish

---

## 🛠 Texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| **Python 3.10+** | Asosiy til |
| **Streamlit** | Veb-interfeys |
| **ccxt** | Birjalar bilan aloqa |
| **pandas** | Ma'lumot qayta ishlash |
| **Plotly** | Grafiklar |
